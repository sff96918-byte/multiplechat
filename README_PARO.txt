রাস্তা ১ (সবচেয়ে সহজ — EXE লাগে না):
  1. ফ্রেশ খালি ফোল্ডারে এই zip extract করো
  2. double-click:  run_dashboard.bat
     (প্রথমবার aiohttp+PyQt6 নিজে install হবে)
  3. MOOD পেজ খুলবে → mood বাছাই → ⚙️ Bot Setup → START

রাস্তা ২ (EXE চাই — নিজের PC-তে বানাও):
  1. double-click:  build_exe.bat  (2-5 মিনিট, net লাগবে)
  2. EXE তৈরি হবে:  dist\EVA Dashboard\EVA Dashboard.exe
  3. চালাতে হবে "EVA Dashboard" ফোল্ডারটা পুরোটা একসাথে
     (exe + _internal + configs — আলাদা করে exe চালালে
      python314.dll error খাবে)
