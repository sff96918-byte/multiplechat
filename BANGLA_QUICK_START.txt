ধাপ ১ — Python চেক
─────────────────
Command Prompt খুলে:  python --version
3.10+ হলেই হবে। না থাকলে python.org থেকে install করো।

ধাপ ২ — DASHBOARD চালু (সবচেয়ে সহজ) ✨
─────────────────
double-click:  run_dashboard.bat
(প্রথমবার PyQt6+PDF নিজে install হবে, net লাগবে)
→ MOOD পেজ খুলবে — ২টা card:

  🌐 LIVE BROWSER MOOD — ব্রাউজার চোখের সামনে চলবে,
     বট লাইভ auto-reply করবে + session auto-save (প্রতি 60s)
  🔑 SESSION CHAT MOOD — ২টা অপশন:
     Option 1: লাইভ ব্রাউজার চালু করে session collect
     Option 2: পুরনো saved session দিয়ে সরাসরি চ্যাট

ধাপ ৩ — BOT SETUP (একবারই)
─────────────────
যেকোনো mood dashboard-এর ডান-উপরে  ⚙️ Bot Setup  চাপো:
  • Engine: flow (funnel logic) বা fixed (line-by-line SMS)
  • fixed হলে: configs/fixed_script.txt এডিট করো
    (প্রতি লাইন = একটা reply, '#' = comment)
  • flow হলে: Snap username দাও বা configs/snap.txt বানাও
    (configs/snap.txt.example → copy করে নাম বদলাও)
  • 💾 SAVE SETUP চাপো

ধাপ ৪ — চালাও
─────────────────

   session mood:  Option 1 (session না থাকলে) বা Option 2
3.  ▶ START  চাপো — LIVE LOG-এ সব দেখা যাবে
